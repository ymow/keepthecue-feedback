# Keep the Cue

[Open the subtitle editor](https://keepthecue.web.app/) to replace text in an SRT while keeping the original cue numbers and timecodes. You can preview corrections before downloading the revised subtitles. The subtitle file stays in your browser.

[Try the three-caption walkthrough](https://keepthecue.web.app/guide.html) with an original SRT and an approved text file.

[Report an editing problem or request a workflow](https://github.com/ymow/keepthecue-feedback/issues/new/choose). This tracker is public. Use invented examples and leave out client material.
